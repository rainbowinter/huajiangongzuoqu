# 新功能

## 2.1.0

### 复制图片 = 复制原图

预览里的图片现在有「复制图片」（悬停右上角，或右键）。复制出来的东西**同时是原文件
和地址**：

- 粘到资源管理器、Word、微信里 —— 得到的是磁盘上的原图文件；
- 粘回花笺的 Markdown 编辑器 —— 得到的是 `![](路径)`，不会再多存一份副本。

图片类文件自己的预览（打开一张 `.png`）也有同样的入口。

### 工作区文件可以复制和拖出去了

- 右键目录里的文件或文件夹 →「复制」，到资源管理器粘贴就是复制文件；
- 更直接：按住左键从目录树**拖到资源管理器窗口**里，松手就完成了。

### 目录树记得你上次展开到哪

每个工作区分别记住展开的目录；切走再切回来、或者重开应用，都不用从头一层层点开。
笔记分类的折叠状态也一起记住了。

### 目录三种显示方式

搜索框右边的「查看方式」是一个下拉菜单，每个工作区各记各的：

- **列表**：一行一个，类型图标 + 文件名；
- **卡片**：标题、日期、时间、大小、正文前几个字（原来的样子，默认）；
- **图标**：像资源管理器的大图标视图，**图片直接显示缩略图**；每层的**文件夹仍然
  一行一个排在最上面**，只有文件进网格。

图片多的目录里，**拖动侧栏边框不再卡**：宽度先跟手变化，缩略图等松手后再渲染。

### 像资源管理器一样多选和批量操作

- `Ctrl + 点击` 加选、`Shift + 点击` 选一段；在目录树**空白处按住左键拖拽**可以框选；
  条目铺满时，也可以从**左侧活动栏那一列**往右拖，或滚到列表末尾的空白处起手；
- 选中多项后右键：**复制、复制文件路径、移动到…、删除** 一次完成；
- `Delete` 删除、`Ctrl+C` 复制文件、`Ctrl+V` 粘贴到当前文件夹；
- 删除 / 移动 / 粘贴前都会弹确认框，文件夹会连同里面所有文件一起处理。

### 「移动到…」是一棵能展开的文件夹树

不再把几十个路径平铺在一大片里；选目标时逐级展开，点哪一层就移到哪一层。
正在移动的文件夹自己（以及它里面的目录）会变灰，不能选。

### 从外面拖进来、粘贴进来都是「复制」

从资源管理器把文件或文件夹**拖到左侧目录树的某个文件夹上**，松手前会先问
「确定复制…到…吗」；拖到空白处则进当前焦点文件夹。按 `Ctrl+V` 同理。
文件夹会连整棵子树一起复制。

### 右键多了三项

- **复制文件路径**：一次复制一条或多条绝对路径；
- **打开方式…**：用电脑上别的程序打开这个文件；
- **属性**：打开资源管理器原生的属性页。

### 就近新建，就地重命名

- 每个文件夹悬停时右边会出现 **`+`**，点它直接在这个文件夹里新建；
- 顶上的「新建文件」会落在**当前打开文件所在的文件夹**，按钮右边会显示目标文件夹名；
- 新建和重命名都是行内卡片，直接敲名字，`Enter` 确认、`Esc` 取消；
- 扩展名没有被任何文件类型认领时会报错、**不会创建**。

### 标签页

顶部多了一条标签条，可以在打开过的多个文档之间快速切换，不用每次回侧栏找。
每个标签前面带**文件类型图标**，一眼能分清笔记、Markdown、代码还是图片。

- **Ctrl + 点击**、**中键**、或右键「在新标签页中打开」会另开一个标签；
- 切换标签前会自动保存当前文档；点标签右边的 `×` 关闭。

> 左右并排的分屏留到下一期 —— 这一期先把标签页做稳。

### 说明文档也能进标签页，自定义样式的说明搬了家

- 「关于 → 说明文档」里的每一篇现在会像文件一样**打开成标签页**，可以和笔记并排
  切换、单独关掉；
- 新增一篇**「自定义样式」**：变量速查表、分主题覆盖、一百多个语义钩子、覆盖 Tailwind
  的做法，以及一段可以直接抄的完整例子；
- 样式文件夹里的 `custom.css` **出厂是空文件**了 —— 说明不再塞在那份 CSS 的注释里，
  打开「自定义样式」照着改即可。

## 2.0.4

### 更新会自己发现了

以前只在**启动时**看一眼有没有新版本 —— 电脑常年开着、花笺一直挂在托盘里，就等于永远
不看了，新版本发出来也收不到提示。

现在：启动后查一次，之后**每 4 小时**再查一次；从后台切回来（比如笔记本合盖唤醒）时，
距离上次检查超过半小时也会补查一次。

仍然是**看到了才提示，点一下才下载、再确认才安装**，不会自己偷偷更新。

### 本地路径的图片能显示了

```text
![一张图](E:/我的项目/实验记录/fig.png)
```

这种引用以前要么整段显示成一串文字、要么只剩一个破图标。现在能正常显示了，路径里有空格
也行。前提是那个文件夹已经挂在左侧工作区里。

## 2.0.3

### 导出 PDF 重做了一遍

- **左边设置、右边预览**，而且预览就是导出的那份文件 —— 页数、断页、表格在哪里切，
  全由浏览器排版引擎决定，跟最终 PDF 逐页对得上。
- 「保存为 PDF」出的仍是**真文字**：能选中、能搜索、能复制。
- 「打印…」换成了 **Windows 自己的打印对话框**：打印机列表、份数、纸张都在那儿，
  接上打印机就能直接打。
- 颜色只剩**彩色 / 黑白**两档。黑白会连图片一起去色，适合投稿要求灰度图的场合。

### 编辑器有滚动条了

编辑、分栏、预览**共用一条**。分栏时左右两栏各自不再显示滚动条，只在整块区域最右边留
一条，拖它两栏一起滚 —— 长文不用再靠滚轮一格一格翻到底。

### 预览可以缩放了

- **Ctrl + 滚轮**缩放，以鼠标指针所在的位置为中心；
- **空格 + 左键拖动**平移；
- 缩小时内容保持在中间，放大后横竖都能滚。

### 在分类里直接新建笔记

每个分类那一行右边的「+」可以直接在这个分类里建笔记，不用先建再拖。

## 2.0.2

### 插件的「详细信息」

插件面板里每一个插件现在都有一个**「详细信息」**按钮。点开会在正文区给出一份这个插件
自己的说明：它是干什么的、版本与作者、声明了哪些权限、加了哪些按钮和面板、有哪些可以调的
设置。

装了一堆插件却不知道哪个是哪个的时候，比来回开关试着看快得多。

### 段落对齐：居左 / 居中 / 居右

工具栏最右边新增三个按钮。选中一段点一下就能居中或靠右，**再点一下取消**。

写进笔记的是 `::: center` 这样的纯文本，**不是 HTML 标签** —— 笔记拿到别的地方仍然是
干净的 Markdown。

### 表格也能一键复制了

预览区里把鼠标移到**表格**上，右上角会出现「复制」。复制出来的是**带 `|` 的原文**，
粘回笔记里还是表格。（代码块的复制按钮一直都在，也是悬停才出现。）

### 表格的列对齐修好了

`| :---: |` 这种写法以前**完全不起作用** —— 不管怎么写都是靠左。现在三种都正常了：
`:---` 靠左、`:---:` 居中、`---:` 靠右。

### 反引号不再「爬」到上一个字头上

写行内代码 `` `m` `` 的时候，那个小撇以前会压到 `m` 的头顶上，看着像给字母加了个重音，
删掉才恢复正常。这是自带中文字体里这个字符的字形问题，现在换了个字体来画它。

### 挂后台时会释放内存

花笺为了「快速记事本」能秒开，会预先建好两个隐藏窗口备用 —— 代价是**一直占着大约
200MB**，哪怕你一个记事本都没开。

现在：**所有窗口都收起来超过 5 分钟后**，这两个备用窗口会被真正关掉，内存还给系统；
你下次打开窗口时它会自动补回来，秒开手感不变。

也就是说 —— **收进托盘放着的时候，它不再白占那 200MB 了。**

### 自动检查更新

装了这个版本之后，花笺启动时会自己去看看有没有新版本，有的话在**右上角**提示你。
不点它就不会下载，下载完也要你再确认才会安装重启。

> 更早的版本（1.0.7、2.0.0）没有这个功能，收不到提示 —— 这一版需要手动装一次。
> 从这里之后就能自动了。

### 其它修复

- 在工作区里打开文件时，笔记列表不会再多出一条打不开的「幽灵条目」了。
- 从工作区切到别的笔记时，最后那零点几秒打的字不会再丢。

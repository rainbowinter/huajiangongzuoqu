# 新功能

## 2.0.2

### 插件的「详细信息」

插件面板里每一个插件现在都有一个**「详细信息」**按钮。点开会在正文区给出一份这个插件
自己的说明：它是干什么的、版本与作者、声明了哪些权限、加了哪些按钮和面板、有哪些可以调的
设置。

装了一堆插件却不知道哪个是哪个的时候，比来回开关试着看快得多。

### 段落对齐：居左 / 居中 / 居右

工具栏最右边新增三个按钮。选中一段点一下就能居中或靠右，**再点一下取消**。

写进笔记的是 `::: center` 这样的纯文本，**不是 HTML 标签** —— 笔记拿到别的地方仍然是
干净的 Markdown。

### 表格也能一键复制了

预览区里把鼠标移到**表格**上，右上角会出现「复制」。复制出来的是**带 `|` 的原文**，
粘回笔记里还是表格。（代码块的复制按钮一直都在，也是悬停才出现。）

### 表格的列对齐修好了

`| :---: |` 这种写法以前**完全不起作用** —— 不管怎么写都是靠左。现在三种都正常了：
`:---` 靠左、`:---:` 居中、`---:` 靠右。

### 反引号不再「爬」到上一个字头上

写行内代码 `` `m` `` 的时候，那个小撇以前会压到 `m` 的头顶上，看着像给字母加了个重音，
删掉才恢复正常。这是自带中文字体里这个字符的字形问题，现在换了个字体来画它。

### 挂后台时会释放内存

花笺为了「快速记事本」能秒开，会预先建好两个隐藏窗口备用 —— 代价是**一直占着大约
200MB**，哪怕你一个记事本都没开。

现在：**所有窗口都收起来超过 5 分钟后**，这两个备用窗口会被真正关掉，内存还给系统；
你下次打开窗口时它会自动补回来，秒开手感不变。

也就是说 —— **收进托盘放着的时候，它不再白占那 200MB 了。**

### 自动检查更新

装了这个版本之后，花笺启动时会自己去看看有没有新版本，有的话在**右上角**提示你。
不点它就不会下载，下载完也要你再确认才会安装重启。

> 更早的版本（1.0.7、2.0.0）没有这个功能，收不到提示 —— 这一版需要手动装一次。
> 从这里之后就能自动了。

### 其它修复

- 在工作区里打开文件时，笔记列表不会再多出一条打不开的「幽灵条目」了。
- 从工作区切到别的笔记时，最后那零点几秒打的字不会再丢。

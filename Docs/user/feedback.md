# 意见反馈

## 哪里提

到仓库的 Issues 页留言：**https://github.com/rainbowinter/huajiangongzuoqu/issues**

点「New issue」，简单写几句就行 —— 不用写得像正式报告，能看懂就够。

## 写什么最有帮助

按有用程度排：

1. **怎么复现**：你做了什么操作、期望看到什么、实际看到什么。三步以内说清最好。
2. **截图 / 录屏**。界面问题一张图胜过一段话。
3. **版本号**：设置面板底部能看到；托盘图标右键的「关于」里也有。
4. **你的环境**：Windows 还是 macOS、大概什么版本。只在某个平台上出现的问题，这条是关键。

## 想要新功能

也欢迎。请顺手说一句**你拿它干什么用** —— 「我想要 X」往往不如「我要做 Y，现在得手工
做 Z，很麻烦」有用：知道了用途，有时候有更合适的做法。

## 遇到问题先试这两下

- **界面看起来不对 / 点不动**：先切一下别的笔记再切回来，或者重启一次。
- **某个插件没反应**：到插件面板看它是不是被关掉了，或者上面有没有红色的错误提示。

## 关于数据

花笺**不联网**（检查更新除外，而且它只发一个请求去问版本号），你的笔记全部在本地磁盘上，
不会上传到任何地方。

所以反馈问题时**不要贴整篇笔记**，除非你确实需要 —— 贴相关的几行就够了。

# 使用指南

花笺是一款**本地优先**的 Markdown 笔记软件：笔记就是你磁盘上的 `.md` 文件，不联网也能用，
换台电脑拷走文件夹就能接着写。

---

## 一、笔记

### 写

左侧栏是笔记列表，点「新建」开一篇。正文区支持完整的 Markdown，边写边在右侧看渲染结果
（工具栏上方可以切「编辑 / 分栏 / 预览」）。

**常用快捷键**

| 按键 | 作用 |
|---|---|
| `Ctrl + B` / `Ctrl + I` | 粗体 / 斜体 |
| `Ctrl + /` | 当前行变成标题（连按升一级） |
| `Ctrl + \` | 插入表格 |
| `Ctrl + Shift + K` | 删除线 |
| `Ctrl + ` ` | 行内代码 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做（**每篇笔记各有一份独立的撤销记录**，切回来还能接着撤） |

### 段落对齐

工具栏最右边三个按钮：**居左 ⇤ / 居中 ⇔ / 居右 ⇥**。选中一段（或把光标放进去）点一下
就生效，**再点一下取消**。

写进笔记里的是这样的纯文本，不是 HTML 标签：

```text
::: center
这一段会居中
:::
```

> 内容以**列表、表格、引用**结尾时，收尾的 `:::` 前面要空一行 —— 这是 Markdown 本身的
> 规矩（紧跟着的那行会被当成上一项的内容）。点按钮时会**自动帮你补上**，手写时才要注意。

### 复制表格与代码

鼠标悬停在预览区的**表格**或**代码块**上，右上角会出现「复制」。表格复制出来的是**带 `|`
的 markdown 原文**，粘回笔记里还是表格；代码块复制的是代码本身。

### 图片

直接把图片粘进正文即可，图片会存到笔记目录里。也可以用 `![说明|300](图片地址)` 控制
宽度与左右位置（`|300` 是宽度，`|left` / `|right` / `|center` 是位置）。

也可以引用**磁盘上已经有的图片**，直接写完整路径就行：

```text
![B1 相对 A0 的结构改动](E:/我的项目/实验记录/fig_b1_arch.png)
```

路径里有空格也没关系 —— 不用写成 `%20`，也不用加尖括号。前提是那个文件夹已经挂在
左侧的**工作区**里（花笺只允许读取工作区里的本地文件）。宽度与位置的写法同上。

### 复制图片

在预览里把鼠标移到图片上，右上角会出现**「复制图片」**；右键图片也有同一项。图片类
文件（`.png` / `.jpg` 等）在预览区同样有这两个入口。

复制出来的内容同时有两种形态：

- 粘到**资源管理器、Word、微信**里 —— 得到的是**磁盘上的原图文件**，不是一张截图；
- 粘回**花笺的 Markdown 编辑器**里 —— 得到的是图片地址（`![](路径)`），不会再多存
  一份副本。

### 标签页

顶部有一条标签条：点一下切换，点标签右边的 `×` 关闭。打开过多个文档时，可以在它们
之间来回切换而不用重新从侧栏找。

想保留当前文档、同时另开一个：

- 在侧栏的笔记 / 文件上 **Ctrl + 点击**，或者**点鼠标中键**；
- 或者右键 →「在新标签页中打开」。

> 切换标签前会自动保存当前文档；关闭最后一个标签会回到空状态。标签不会被记住到下次
> 启动（重开应用回到第一篇笔记）。

### 导出 PDF / 打印

点工具栏的**「导出…」**按钮（那个向下的箭头），选 **「导出 PDF（预览并调纸张、边距…）」**，
打开导出面板：左边是缩放、纸张（含横向）、页边距、页眉页脚、标题、颜色，右边是**排好版的
预览**。

那份预览就是「保存为 PDF」会写出来的文件本身 —— 页数、断页、表格在哪里切开都对得上。
预览里可以用 Ctrl + 滚轮缩放（以指针为中心）、空格 + 左键拖动平移。

两个按钮：

- **保存为 PDF**：选个路径直接写文件，不弹任何对话框。产出是**真文字**，能选中、能搜索。
- **打印…**：弹出 **Windows 自己的打印对话框** —— 打印机列表、份数、纸张都在那儿，
  接上打印机就能直接打。

配色只有两档：**彩色**（屏幕上什么样就印什么样）和**黑白**（连图片一起转成灰度，
适合投稿要求灰度图的场合）。

## 二、快速记事本

按全局快捷键（默认可以在「设置」里改），任意时刻弹出一个**悬浮小窗**，随手记两句话，
关掉就没了。适合「正在做别的事，突然想到一句话」的场景。

主窗口关掉是**收进托盘**，不是退出 —— 托盘图标上右键可以退出。

---

## 三、工作区

「工作区」可以把一个文件夹挂进来（比如某个项目的目录），在软件里直接看和改里面的文件。
支持代码、文本、Markdown、表格、图片、PDF 等的预览。

> ⚠️ 在工作区里打开的**可编辑**文件（`.md`、`.txt`、代码等），保存会**直接写回原文件**。
> 打开别的项目的文件时留意一下。

### 目录树的三种样子

目录树右上角的「查看方式」是一个下拉菜单：

- **列表**：一行一个，类型图标 + 文件名，目录很深的时候最省地方；
- **卡片**（默认）：标题、日期、大小，外加正文的第一行；
- **图标**：像资源管理器的大图标视图，文件一行排好几个，其中**图片直接显示缩略图**。
  每一层的**文件夹仍然一行一个、排在最上面**，只有文件进图标网格 —— 文件夹多的时候
  不会把整屏铺满图标。

每个工作区各记各的；**展开到哪几层也会被记住**，下次切回来或重开应用不用重新展开。

搜索框右边有一颗**刷新**按钮：

- **左键**：立即重新检查**已经打开的文件夹**（根目录 + 你展开过的那些），不会去扫
  整个工作区；外部新增 / 删除 / 移动的文件会立刻出现或消失；
- **右键**：切换**自动检测** —— 图标会从刷新箭头变成脉冲，按钮高亮、右上角亮一颗
  小圆点；再右键一次换回来。自动检测每 5 秒检查一次已打开的文件夹。
  **按工作区单独设置，默认关闭**（一直轮询大目录会有负担）；窗口在后台时暂停，
  切回前台补查一次；
- 在脉冲模式下**左键仍然是刷新**，不会退出自动检测。

### 多选与批量操作

- **Ctrl + 点击**加选 / 取消一项，**Shift + 点击**选一整段；
- 在目录树**空白处按住左键拖拽**可以框选，矩形碰到哪几项就选中哪几项（子目录里的
  文件也算）。条目把目录树铺满、找不到空白时，可以从**左侧活动栏那一列**（或侧栏里
  目录树之外的空白）按住左键往右拖；列表滚到底也留了一块空白可以起手。
- 选中多项后右键，可以一次**复制、复制文件路径、移动到…、删除**；
- 快捷键：`Delete` / `Backspace` 删除，`Ctrl+C` 复制文件，`Ctrl+V` 粘贴到当前文件夹。

删除、移动、把剪贴板里的文件粘贴进来之前都会弹确认框。

### 新建与重命名

- 顶上那个「新建文件」会创建在**当前打开文件所在的文件夹**（没有打开文件时是根目录，
  按钮右边会显示目标文件夹名）。
- **把鼠标移到文件夹上**，右边会出现一个 **`+`** —— 点它就在那个文件夹里新建。
  （笔记分类那一行同理：悬停才显示「在这个分类里新建」。）
- 新建与重命名都是**行内卡片**：直接输入文件名，`Enter` 确认、`Esc` 取消。重命名时
  卡片不会显示类型图标。
- 文件名要带扩展名。**扩展名没有被任何文件类型认领时会报错、不会创建**（装了
  file-reader 之后 `.txt` / `.py` / `.csv` 等都算认领）。重命名同理。

### 复制、拖出、拖入与「移动到」

- 右键文件或文件夹 →「复制」：粘到资源管理器里就是**复制这个文件 / 文件夹**，
  粘到 Word 等程序里也会当文件处理。
- 也可以**直接按住左键从目录树里拖出去**，拖到资源管理器窗口里即完成复制。
- 反过来，从资源管理器**拖进目录树**（或按 `Ctrl+V`）会把文件**复制**进来：拖到哪个
  文件夹上就进哪个；拖到空白处则进当前焦点文件夹。松手/粘贴前会先问一次。
- 拖动文件夹会连里面所有文件一起复制。
- 右键 →「移动到…」会打开一棵**可以逐级展开**的文件夹树，选好目标再确认，不用在
  一长串路径里找。
- 右键还有「复制文件路径」「打开方式…」（用电脑上别的程序打开）与
  「属性」（打开资源管理器原生的属性页）。
- 右键文件 →「在新标签页中打开」，会保留当前文档并另开一个标签。

## 四、插件

插件是花笺扩展功能的方式。内置了十几个，在「插件」面板里可以一个个开关。

- **公式面板**：152 个常用数学符号 + 28 个结构模板（分式、积分、矩阵……），点一下插到
  光标处，不用记 LaTeX 命令。
- **取色板**：常用颜色的快捷插入。
- **大纲**：按标题层级列出当前文档，点一下跳过去（Markdown / CSS / SCSS 都支持）。
- **字数统计**、**行号**、**插入时间戳**、**字体包**（给代码换个更好看的等宽字体）等。

每个插件在面板里都能展开看它的**参数**，点「详细信息」会告诉你**这个插件具体做了什么**
（它声明的权限、加了哪些按钮、有哪些可调的设置）。

插件也可以自己写 —— 一个文件夹 + 一个 `plugin.json` 就能跑。

## 五、外观

「设置」里可以改主题（浅色 / 深色 / 黛紫 / 樱粉）、字号、行距、代码字体，以及界面缩放。

想更彻底地自定义外观，可以自己写 CSS 放进**样式文件夹**（右侧栏的「样式」面板里能打开它，
设置 → 外观 → 界面样式里也能看到它在哪）。**这一步不需要装任何插件** —— 样式表是宿主
自带的能力；css-modifier 只负责按笔记单独挂样式。

- 文件夹里预置的 **`custom.css` 永远生效**，改完保存约两秒后自动套用，不用重启。
  它**出厂是空的**；完整的变量表、语义钩子清单和可直接照抄的例子在
  **「关于 → 说明文档 → 自定义样式」**里（也会打开成一张标签页）。
- 你自己**另外**放进去的 `.css` **默认不生效**：在「样式」面板里把它**开成全局**，
  就套用到每个窗口；也可以**挂到某一个打开的文件**上，只让那个文件变样 ——
  这样试一份新样式不用先改动整个界面。
- 想打开样式目录，用**「样式」面板顶上的「打开文件夹」**（在系统资源管理器里打开）。

## 六、数据在哪

| 内容 | 位置 |
|---|---|
| 笔记 | `文档/花笺/notes` |
| 插件与插件数据 | `文档/花笺/plugins`、`plugin-data` |
| 设置 | 用户目录下的 `floral-notepaper/config.json` |

**全部是本地的。** 卸载软件不会删掉你的笔记；重装后笔记、插件设置都还在。
备份的话，把 `文档/花笺` 整个拷走就行。

# 使用指南

花笺是一款**本地优先**的 Markdown 笔记软件：笔记就是你磁盘上的 `.md` 文件，不联网也能用，
换台电脑拷走文件夹就能接着写。

---

## 一、笔记

### 写

左侧栏是笔记列表，点「新建」开一篇。正文区支持完整的 Markdown，边写边在右侧看渲染结果
（工具栏上方可以切「编辑 / 分栏 / 预览」）。

**常用快捷键**

| 按键 | 作用 |
|---|---|
| `Ctrl + B` / `Ctrl + I` | 粗体 / 斜体 |
| `Ctrl + /` | 当前行变成标题（连按升一级） |
| `Ctrl + \` | 插入表格 |
| `Ctrl + Shift + K` | 删除线 |
| `Ctrl + ` ` | 行内代码 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做（**每篇笔记各有一份独立的撤销记录**，切回来还能接着撤） |

### 段落对齐

工具栏最右边三个按钮：**居左 ⇤ / 居中 ⇔ / 居右 ⇥**。选中一段（或把光标放进去）点一下
就生效，**再点一下取消**。

写进笔记里的是这样的纯文本，不是 HTML 标签：

```text
::: center
这一段会居中
:::
```

> 内容以**列表、表格、引用**结尾时，收尾的 `:::` 前面要空一行 —— 这是 Markdown 本身的
> 规矩（紧跟着的那行会被当成上一项的内容）。点按钮时会**自动帮你补上**，手写时才要注意。

### 复制表格与代码

鼠标悬停在预览区的**表格**或**代码块**上，右上角会出现「复制」。表格复制出来的是**带 `|`
的 markdown 原文**，粘回笔记里还是表格；代码块复制的是代码本身。

### 图片

直接把图片粘进正文即可，图片会存到笔记目录里。也可以用 `![说明|300](图片地址)` 控制
宽度与左右位置（`|300` 是宽度，`|left` / `|right` / `|center` 是位置）。

## 二、快速记事本

按全局快捷键（默认可以在「设置」里改），任意时刻弹出一个**悬浮小窗**，随手记两句话，
关掉就没了。适合「正在做别的事，突然想到一句话」的场景。

主窗口关掉是**收进托盘**，不是退出 —— 托盘图标上右键可以退出。

---

## 三、工作区

「工作区」可以把一个文件夹挂进来（比如某个项目的目录），在软件里直接看和改里面的文件。
支持代码、文本、Markdown、表格、图片、PDF 等的预览。

> ⚠️ 在工作区里打开的**可编辑**文件（`.md`、`.txt`、代码等），保存会**直接写回原文件**。
> 打开别的项目的文件时留意一下。

---

## 四、插件

插件是花笺扩展功能的方式。内置了十几个，在「插件」面板里可以一个个开关。

- **公式面板**：152 个常用数学符号 + 28 个结构模板（分式、积分、矩阵……），点一下插到
  光标处，不用记 LaTeX 命令。
- **取色板**：常用颜色的快捷插入。
- **大纲**：按标题层级列出当前文档，点一下跳过去（Markdown / CSS / SCSS 都支持）。
- **字数统计**、**行号**、**插入时间戳**、**字体包**（给代码换个更好看的等宽字体）等。

每个插件在面板里都能展开看它的**参数**，点「详细信息」会告诉你**这个插件具体做了什么**
（它声明的权限、加了哪些按钮、有哪些可调的设置）。

插件也可以自己写 —— 一个文件夹 + 一个 `plugin.json` 就能跑。

---

## 五、外观

「设置」里可以改主题（浅色 / 深色 / 黛紫 / 樱粉）、字号、行距、代码字体，以及界面缩放。

想更彻底地自定义外观，可以写一段 CSS 放进 `custom.css` —— 位置和写法见设置面板里的说明。

---

## 六、数据在哪

| 内容 | 位置 |
|---|---|
| 笔记 | `文档/花笺/notes` |
| 插件与插件数据 | `文档/花笺/plugins`、`plugin-data` |
| 设置 | 用户目录下的 `floral-notepaper/config.json` |

**全部是本地的。** 卸载软件不会删掉你的笔记；重装后笔记、插件设置都还在。
备份的话，把 `文档/花笺` 整个拷走就行。

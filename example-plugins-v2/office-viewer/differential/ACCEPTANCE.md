## 编辑回放：6/10

已通过：E01 段中插入、E03 段首退格合并、E04 段尾 Delete 合并、
E05 Shift+Enter、E07 撤销重做、E10 多行粘贴。

未通过 4 条：

### E02 回车分段保留段落格式

失败项：`p0_keeps_firstLineChars`、`p0_keeps_line`、`p1_keeps_firstLineChars`、`p1_keeps_line`

**现象**：在带 `firstLineChars=200` / `line=1.5` 的段落中间回车，两个段落的
段落格式都丢了（或只剩一段有）。

**期望**：新段克隆 `w:pPr`（含 `ind` / `spacing`），但**不复制 `w:sectPr`**。

### E06 跨 run 删除

失败项：`text`、`last_run_still_plain`

**现象**：从粗体 run 的第 1 个字选到普通 run 的第 3 个字再退格，文本结果不对，
且剩余 run 的 `rPr` 被污染。

**期望**：结果 `甲丁`；两个 run 的 `rPr` 不混合；清空后的 run 被清理。

### E08 列表项开头退格

失败项：`second_still_numbered`、`second_renumbered_1`

**现象**：第一项开头退格后，第一段 `numPr` 去掉了，但第二项仍在编号里，
且没有重排为 1。

**期望**：第一段失去 `numPr`；第二段编号重排为 1。

### E09 空列表项回车

失败项：`empty_item_keeps_numPr`、`new_item_same_numId`

**现象**：空列表项回车后，空项没保留 `numPr`，新项 `numId` 也不一致。

**期望**：空项保留 `numPr`；新项与空项 `numId` 相同（继续编号）。

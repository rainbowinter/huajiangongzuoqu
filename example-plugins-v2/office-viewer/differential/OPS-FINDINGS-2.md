## 这一轮修掉的测量问题（都不是插件 bug）

| 问题 | 现象 | 修法 |
|---|---|---|
| `caret_equal` 缺数据判失败 | 两端 caret 都是 `None` 时 `checks` 里没有这个键，被当成 false | 双方都缺失时视为不参与判定 |
| WPS 光标落在段边界 | 回车后 `position == 上一段 end`，被算成上一段末尾 | 段尾位置归下一段 offset 0（最后一段除外） |
| 软换行被吞 | WPS 投影把 `\v` 删了，插件是 `\n` | 投影保留 `\v`，比较时归一成 `\n` |
| 粗体按 run 比 | WPS 逐词切 run，软换行/标点单独成 run | 按**字符**展开后比布尔序列 |
| 编号 ID 跨实现比较 | WPS 的 `numId` 是运行时哈希、`ilvl` 报成 1 | 只比“有没有编号”的布尔值 |

这些都在 `tools/run_ops.py` / `tools/wps_ops.ps1` 里，属于**验收侧**的驱动与比较逻辑。

## pending 与后续

### O19–O22 撤销/重做：pending

WPS 的 `Selection` 上没有 Undo/Redo 命令，驱动无法执行 `Ctrl+Z/Y`。
`run_protocol.py` 里已加 `PENDING_OPS = {"O19","O20","O21","O22"}`，
不进入 ops 结果。

补驱动的方式（下一步）：用 `Document.Undo()` / `Document.Redo()`，
按 `Ctrl+Z` 映射到 `$doc.Undo()`。补完后从 `PENDING_OPS` 移除即可。

### 表格操作：pending

`run_protocol.py` 的 `ALLOWED_OPS` 仍不含 `table`；表格编辑（M7）落地后
再加 O27–O28。

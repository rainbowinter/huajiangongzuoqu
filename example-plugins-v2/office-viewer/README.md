# Word 文档

在花笺里直接打开 `.docx`，按 Word 的规则断行、排版与分页。

> **当前状态：M5 / M6 第一版。** 能打开真实的 `.docx`，按 Word 的规则排版分页；可以
> 点击落光标、拖选、输入（含中文输入法）、回车分段、退格合并、撤销重做，并把修改
> **另存为**新的 `.docx`。原文件永远不会被改写。

## 用它

在工作文件夹里点一个 `.docx`，或者用「打开文件」选一个。打开后会看到 A4 纸（尺寸和页边距
取自文档的 `w:sectPr`），文字按 Word 的行距、缩进和对齐方式排好。

在花笺里「新建文件」并写 `.docx` 时，宿主会直接写入这份最小 DOCX 骨架（插件在
`files.registerType` 的 `newFile` 里声明），不是 0 字节文件 —— 双击就能打开，右键用
Word 打开也认。

旧版本建出来的 **0 字节 / 纯文本 `.docx`** 仍然兼容：打开时在内存里换成一份最小合法
DOCX（纯文本会原样放进正文），之后照常编辑、另存。

预览区顶上那排是工具栏：

| 控件 | 干什么 |
|---|---|
| `−` / `+` | 缩小 / 放大（Ctrl + 滚轮也行） |
| 比例 | 当前缩放比例 |
| 适应宽度 | 按窗口宽度铺满 |
| `‹` / `›` | 上一页 / 下一页 |
| 页码框 | 输入页码回车跳转 |
| 单页 / 连续 | 一次只显示一页，还是连着往下滚 |
| 另存为 | 把当前修改另存成一个新的 `.docx`（Ctrl+S 也行） |

### 编辑与另存

* **点一下**落光标，**拖动**或 Shift + 点击选文字，**双击**选词。
* 直接输入；中文输入法的组合文字会先显示在光标处，提交后才写进文档。
* `Enter` 分段，`Shift+Enter` 段内换行，`Backspace / Delete` 删字；在段首退格、段尾
  删除会与相邻段落合并。文字会直接写回 `word/document.xml`，不是只改显示。
* **列表编辑**：列表项开头按 `Backspace`，第一次只去掉项目符号 / 编号（多级列表先降
  一级），文字保留；再按一次才与上一段合并。空列表项按 `Enter` 会保留这一项的编号，
  并在下面继续生成下一个编号项；要退出列表，用这一项开头的 `Backspace` 去掉编号。
* 选中多段后按 `Backspace / Delete` 可以跨段删除并合并；在段首 / 段尾退格或删除会与相邻段落合并。
* **表格单元格可以直接编辑**：点进单元格落光标，输入、回车分段、退格合并、选中加粗/斜体等。
  表格结构（增删行列、合并单元格、列宽拖动）暂时不改。
* `Ctrl+Z / Ctrl+Y` 撤销重做（连续输入会合成一步），`Ctrl+A` 全选，`Ctrl+C / X / V`
  复制剪切粘贴（多行粘贴会分段，制表符会变成真正的 `w:tab`）。
* 有未保存的修改时，底部状态条会显示「未保存」。
* **另存为**只写新文件，原文件不动；默认文件名是 `原名-已编辑.docx`。宿主只负责弹
  系统保存对话框，插件拿不到「用户到底保存了没有」的回执，所以提示只说「已打开保存
  对话框」。
* 保存时**只重新序列化 `document.xml`**，图片、样式、主题、关系等其它部件原样搬回
  （未做修改时连 XML 都不碰，字节完全一致）。

### 「开始」面板（全局右侧栏）

打开一份 Word 文档后，主窗口顶上那一行会出现一个 **「开始」** 页签 —— 它和「目录」
在**同一级**，点开就是花笺最右侧的侧拉栏。换成别的文件时，这个页签会自动消失。

面板里是 Office 风格的格式入口：

* **字体组**：按 Word / WPS 的样子排成两行 —— 第一行是字体、字号下拉框与 A⁺ / A⁻，
  第二行是加粗、斜体、下划线、删除线、上下标、颜色等按钮，块与块之间用细线分开，
  右下角有一个小箭头。点箭头，**整个侧栏**会换成详细字体页（顶部有「← 返回」），
  里面是「中文字体 / 字形 / 字号」「西文字体」「复杂文种」「所有文字」「效果」「预览」。
  **字体、字号下拉框**在未知时**留空**（和 Word 一样），选了具体值后立即预览；
  **加粗 / 斜体 / 下划线 / 删除线 / 上下标**在选中文字后直接写回 XML；字体颜色、
  高亮与详细字体页里的其余复选框仍是占位。「段落」与「显示」也各自放在一个圆角框里。
* **段落组**：同样是 Word / WPS 的两行图标布局，右下角也有小箭头。
  * 第一行：项目符号、编号、减少 / 增加缩进量、排序、¶ 编辑标记（¶ 可以点，其余占位）。
  * 第二行：左对齐 / 居中 / 右对齐 / 两端对齐、行距下拉框、底纹与边框（占位）。
  * 点右下角箭头进入「缩进和间距」详细页：对齐方式、段前、段后、行距。
  * **对齐与行距现在就能生效**，其余控件等 M5。和字体一样，**这一版是整篇预览**——
    最终要像 Word 一样按选区或段落生效，那要等编辑模式（M5）接入。改了立即重排，
    不修改原文件，点「恢复文档原样」就回到文档自己的格式。
* **显示**：
  * **段落标记**：¶ 段落结束、↵ 手动换行、→ 制表符、· 空格。标记是零宽的，打开不会改变排版。
    入口在段落组第一行的 ¶ 图标。
  * **段落序号**：在页面左侧空白处给每个段落编号。这是花笺自己的阅读辅助，Word 没有。

### 已经支持的 Word 格式

* 段落：对齐、左右缩进、首行缩进 / 悬挂缩进、段前段后、单倍 / 多倍 / 固定行距、
  文档网格（中文 Word 默认的对齐方式）。
* 字符：中西文字体、字号、粗体、斜体、下划线、删除线、颜色、高亮、上下标、字符间距。
* 样式：`docDefaults` → 段落样式 `basedOn` 链 → 字符样式 → 直接格式。
* 主题字体（`theme1.xml`），以及 `w:rFonts` 里的 `ascii` / `eastAsia` 分流。
* 自动编号：常见的十进制、字母、罗马数字、中文数字与项目符号。
* 图片：内联图片按原始尺寸**占满行高**（图片后面不会再压字）；浮动图片按 `wp:anchor`
  的段落 / 栏偏移定位，`behindDoc` 的放在文字下面。WMF / EMF 这类浏览器画不了的会显示占位框。
* 表格：右侧新增 **「插入」面板**（与「开始」同级），里面有 **8×8 的插入表格网格**，
  从左上角拖到目标格时整块矩形会高亮，点击目标格即在当前段落后插入新表；图片 / 形状 / 文本框 / 符号 / 公式目前是占位。
  已有表格按真实网格排版 —— 列宽、`gridSpan` 横向合并、`vMerge` 纵向合并、表头行重复、
  `cantSplit` 行不拆页、行高（atLeast / exact）、单元格底纹与上下左右边框、垂直对齐。
  单元格里的段落复用正文的断行/行距规则，**可以直接编辑文字**（输入 / 回车 / 退格 /
  选区格式）；暂不支持增删行列、改列宽和跨单元格拖选。嵌套表格暂时按行拍平成文本。

## 验收

`differential/` 是一套与 WPS 导出 PDF 对照的差分测试：28 条排版用例 + 10 条编辑用例。

```bash
cd differential
python tools/run_layout.py      # 排版 → out/<id>.plugin.json
python tools/compare.py         # 对照 → out/report.html
python tools/replay_edit.py     # E01–E10
python tools/test_table_editing.py  # 单元格内输入 / 分段 / 合并 / 选区格式
```

当前基线：**排版 31/31、编辑 10/10、双端操作 26/26、表格编辑 5/5**；判定的是
逐字符文本、断行点、分页点和行首 x / 首行 baseline / 行距，不是截图相似度。
细节见 `differential/FINDINGS.md` 与 `differential/OPS-FINDINGS.md`。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `files:register` | 让侧栏认出 `.docx` 这个扩展名 |
| `files:view` | 交出会在沙箱里真的跑起来的界面代码（解析、排版、分页都在里面），并允许面板向这个视图发格式命令 |
| `editor:read` | 读当前文件身份，判断「开始」页签该不该出现 |
| `ui:panel` | 注册右侧栏的「开始」面板 |
| `ui:style` | 给面板的按钮与分组注入一小段样式 |

沙箱是浏览器的 iframe 沙箱：这段界面代码**读不到你的文件**，也够不到花笺的任何能力 ——
它只能拿到宿主递给它的那一份文档字节。

## 还没做的

* **其余字符格式**：字体颜色、高亮、字符间距、详细字体页里的大部分复选框仍是占位。
* **字体 / 字号 / 对齐 / 行距**：仍是**整篇预览**，不写回 XML。
* **表格结构编辑**：可以插入新表格；增删行列、合并 / 拆分单元格、调列宽还没做；
  嵌套表格按行拍平成文本。
* **`Ctrl+Shift+V` 纯文本粘贴**与撤销栈持久化还没做。
* **页眉页脚、脚注、分节、分栏、文本框、形状、公式、修订**。
* **字体保真**：视图只能用系统字体，文档里没装的字体会回退到宋体 / Arial。
* **打印 / 导出 PDF**。
* **PPT / Excel**：同一个插件以后会加 `.pptx` / `.xlsx`，各自独立的视图包。

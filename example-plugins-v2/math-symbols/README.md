# 公式面板

右侧栏里一版 LaTeX 符号表：**结构模板** + 十个分类的符号，点一下插到光标处。

## 用它

打开右侧栏的**「符号」**面板。分两段：

**上面是结构模板**（分式、根号、上下标、求和 / 积分 / 极限、导数偏导、向量与重音符号、
自适应括号、矩阵、分段函数、多行对齐）。点「分式」插进去的是 `\frac{}{}`，
而且**光标会自动落进第一个 `{}`** —— 接着直接打分子就行，不用自己数括号。

**下面是符号表**，十个分类：

小写希腊字母 · 大写希腊字母 · 运算与算术 · 关系与比较 · 集合与逻辑 · 箭头 ·
大型运算符与微积分 · 括号与定界符 · 数集与花体 · 特殊字符与省略号

**每个格子同时显示字形和 LaTeX 命令** —— 只给字形你不认识，只给命令你不知道是哪个符号，
两样并排才用得上。鼠标停上去还有完整提示（比如 `\varepsilon（varepsilon）`）。

关于包裹（「设置 → 插件 → math-symbols」里的**「自动包裹 $…$」**，默认开）：

| 光标在哪 | 点什么 |
|---|---|
| 已经在一个 `$…$` 里 | 只插 LaTeX 本身 |
| 不在数学环境里 | 自动补上 `$…$` 把式子包起来 |
| 矩阵 / 分段函数这类**独立成段**的模板 | 总是插成 `$$…$$` 块，不受这条设置影响 |

关掉它就永远只插原始 LaTeX —— 你如果本来就习惯自己写 `$$`，关掉更省事。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:panel` | 右侧栏里那个面板 |
| `ui:style` | 面板的悬停与网格样式（一屏上百个格子没有悬停反馈就没法点） |
| `editor:write` | 把符号插进正文 |

插入走的是宿主的**可撤销写入**路径，Ctrl+Z 能一步步退回。颜色全部取自主题变量，
深色 / 浅色主题自动跟着变。

## 还没做的

* **没有搜索框** —— 找冷门符号只能按分类翻。
* **不依赖 KaTeX**：格子里的字形直接是 Unicode 字符，插件跑在沙箱里没法调渲染器。
  冷门字符（黑板粗体、花体）在某些字体下可能缺字，是已知的取舍。
* 符号表是固定的那十类，不能自己加常用符号。
* 不做 LaTeX 到 Unicode 的反查（不会告诉你这个字符该怎么打）。

把 .ttf / .otf / .ttc / .woff / .woff2 字体文件复制到本目录，然后重载插件
（或重启花笺）。

它们会自动出现在「设置 → 代码字体」的「插件字体」分组里。

说明：
  * 只扫描本目录**一层**，子目录里的字体不会被加载。
  * 字体按「用户级」加载，不写系统字体表，不需要管理员权限，卸载插件即全部消失。
  * 单个文件上限 16 MB，超过的会被跳过（多半是误把整个字体包 zip 丢进来了）。
  * 字体族名从字体文件内部读，读不出来的（例如 WOFF）才按文件名猜。
    文件名太怪导致名字不对时，可以在插件 index.js 的 overrides 里手工兜一条。

# 字体包

把自己带的字体文件丢进插件的 `fonts/` 目录，它们就会出现在「设置 → 代码字体」里。

## 用它

1. 把 `.ttf` / `.otf` / `.woff2` 复制到本插件的 `fonts/` 目录
   （插件面板 → 打开插件文件夹 → `font-pack/fonts/`）；
2. 在插件面板里点一次**「刷新」**（或者重启应用）；
3. 「设置 → 外观 → 代码字体」里会多出一组**「插件字体」**，选它就行 ——
   代码编辑器、Markdown 代码块、行内代码一起生效。

族名、字重、字形是**从字体文件内部读出来**的（宿主在 Rust 侧拆开 sfnt 容器读 `name` 与
`OS/2` 表），正常情况下你什么都不用填。

⚠️ **别指望文件名**：`JetBrainsMono-Regular.ttf` 按驼峰拆出来是「Jet Brains Mono」，
而字体的真名是「JetBrains Mono」（没有空格）。真正装了文件时读的是真名，
文件名只在**读不出内部名称**时才当兜底（`.woff` 这种就该注意了）。

## 它要的权限

**一个都不要。** 这个插件只喊一句「我的字体在 `fonts/` 里」：

列目录、把文件变成 WebView 能加载的 URL、拼 `@font-face`、注入样式、登记族名 ——
全部由宿主完成，回给插件的只有字体**名字**。所以它比 `ui.registerStyle`（那个要
`ui:style`）的能耐还小：插件塞不进任意 CSS，规则是宿主按**校验过的文件名**生成的。

## 还没做的

* 只能换**代码字体** —— 正文的衬线 / 无衬线字体还不能换。
* 只认 `.ttf` / `.otf` / `.woff2`。
* 没有「预览」：选之前看不到这字体长什么样。

# 单篇笔记的附加样式

给**某一篇笔记**挂一份 CSS，只有那一篇用得上。

## 用它

1. 把 `.css` 放进这个插件的 `styles/` 目录
   （插件面板 → 打开插件文件夹 → `css-modifier/styles/`）；
2. 在**那一篇笔记**的最开头写：

   ```markdown
   ---
   css: 样式表名
   ---
   ```

   字段名可以改（下面那条设置），默认 `css`；`.css` 后缀写不写都行；
3. 保存即可 —— 那篇笔记立刻套上这份样式，**别的笔记一点不受影响**。

字段名在「设置 → 插件 → css-modifier」里改，默认是 `css`。

面板上还有一颗**「打开样式工作区」**：它把数据目录下的 `styles/` 文件夹加进左侧工作区
并跳过去 —— 那儿放的是**全局**样式表，省得你去文件管理器里翻。

> **想改整个界面，不是这里。** 全局样式表在数据目录的 `styles/` 下，入口是右侧栏的
> **「样式」面板**：`custom.css` 永远生效，同目录里**别的** `.css` 默认不生效 ——
> 在那儿把它们开成全局，或者挂到某一个打开的文件上。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:style` | 把那一段 CSS 注入当前窗口 |
| `ui:panel` | 右侧栏里那个面板 |
| `ui:command` | 「重新读取笔记附加样式」这条命令 |
| `ui:toast` | 读不到样式表时提示你 |
| `ui:row-action` | 插件列表里本插件那一行的「打开样式工作区」按钮 |
| `workspace:folders` | 把数据目录下的 `styles/` 加进工作区 |
| `editor:read` | 读笔记开头的 front-matter |
| `events` | 笔记打开、内容变化时重新套用 |
| `settings` | 读「字段名」这条设置 |

样式是**窗口粒度**的：主窗口、小窗、磁贴各有一份运行时，各自注入。

## 还没做的

* 一篇笔记只能挂**一份**样式表（想要叠加，自己在那一份里 `@import` 是不行的 ——
  注进来的是文本不是 URL，得把那几段直接写在一起）。
* 用**外部编辑器**改 `styles/` 里的文件不会自动重读：只有在花笺里保存才会。
  那种情况点面板上的「重新读取」。
* front-matter 只认平铺的 `key: value`，不解析嵌套与列表。

# 目录

把当前文件的结构列成大纲，点一行跳过去。**代码文件也能用**，不只是 Markdown。

## 用它

打开右侧栏的**「目录」**面板。面板按**当前打开的文件类型**换一套解析规则：

| 文件 | 拿什么当目录 |
|---|---|
| 笔记 / `.md` | Markdown 的 `#` 标题，按层级缩进 |
| `.py` | 行首**缩进**（类 → 方法 → 嵌套函数） |
| `.js` `.ts` `.jsx` `.tsx` | 花括号深度 + 声明关键字 |
| `.json` | 键的嵌套路径 |
| `.css` `.scss` | 规则（选择器）与 `@` 规则，按花括号嵌套 |
| 其它代码格式 | 通用兜底：一套更宽的关键字 + 花括号深度 |
| 认不出的格式 | 明说「该格式没有目录」 |

**点一行**：正文滚到那个位置。看 Markdown 时**预览区也跟着滚** —— 两边对得上。

左边那个灰阶小标（`class` / `def` / `fn` / `key` / `@`…）是给扫读用的：
一列里混着类和函数的时候，一眼就能分出来。

最后那一行「认不出的格式明说没有目录」是**有意的**：拿 Markdown 的规则去扫一个 `.txt`，
结果永远是「暂无标题」，用户只会以为插件坏了。说不支持，比给个假结果强。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:panel` | 右侧栏里那个面板 |
| `editor:read` | 读正文来解析 |

**只读**。跳转用的是宿主的滚动接口，不改正文一个字。

点击时它**重新解析一次**当前正文，而不是把位置记在按钮上 —— 从面板画出来到你点下去
之间，你可能已经改过正文了；重算拿到的才是此刻的位置。

## 还没做的

* **不折叠**：层级是缩进出来的，不能把某一节收起来。
* **不追踪当前位置**：滚动正文时面板里不会高亮「你在这儿」。
* 没有点击复制链接 / 复制标题这类动作，点一下就是跳转。
* `.md` 只认 `#` 标题：不解析 front-matter 里的结构，也不把列表当层级。

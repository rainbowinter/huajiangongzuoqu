# 行号

编辑区左边一栏行号，跟着滚动同步。

## 用它

装上就生效。栏宽在「设置 → 插件 → line-numbers」里调，20–120 像素，**改完立刻生效**：

| 值 | 适合 |
|---|---|
| 20–30 | 短文、想给正文多留点地方 |
| **36（默认）** | 一般笔记 |
| 60–120 | 长文档、或者喜欢对齐着读代码 |

空文档也算一行 —— 刚打开的新笔记会显示一个「1」，而不是空白。

**行号是给眼睛看的，不能点。** 点它不会跳转，也不能选中——想跳到某一行得用编辑器自己的
滚动条。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:gutter` | 在编辑区左侧加一栏旁注 |
| `editor:read` | 读正文，数出一共几行 |
| `events` | 正文变化时重算 |
| `settings` | 读「栏宽」这条设置 |

**插件只负责算出数字，排版一概不管。** 插件跑在 Worker 里没有 DOM，量不到字体和换行
—— 一段文字在屏幕上折成三行，行号却只该出现一次。所以这里的分工是**插件出文字、
宿主出排版**：插件返回一个字符串数组（第 i 项对应第 i 个逻辑行），宿主把每一行的原文
按与编辑器**完全相同的宽度**再排一遍，行高天然就对上了。

## 还没做的

* **不能点行号跳转**，也不能拖动选择整行。
* 不做相对行号（`+3` / `-2` 那种），也没有「当前行高亮」——只有数字。
* 折叠段落之类的不支持：一行就是一行。

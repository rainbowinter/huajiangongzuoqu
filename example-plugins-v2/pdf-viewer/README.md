# PDF 阅读器

在花笺里直接打开 `.pdf`，不用切到别的软件。

## 用它

在工作文件夹里点一个 `.pdf`，或者「打开文件」选一个 —— 它会像图片那样直接显示，
**只读**，不会改动原文件一个字节。

预览区顶上那排是它自己的工具：

| 控件 | 干什么 |
|---|---|
| `−` / `+` | 缩小 / 放大（按住 Ctrl 滚滚轮也行） |
| 比例 | 当前缩放比例 |
| 适应宽度 | 按窗口宽度铺满，再点一下旁边的比例就是手动缩放 |
| `‹` / `›` | 上一页 / 下一页 |
| `3 / 14` | 当前页 / 总页数 |
| 页码框 | 输入页码回车直接跳过去 |
| 单页 / 连续 | 一次只显示一页，还是像网页那样连着往下滚 |
| `⟳` / 角度 | 顺时针旋转 90°，可以转到 0 / 90 / 180 / 270 |

底色、分隔线跟着应用主题走 —— 换了深色或主题色，这边一起换。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `files:register` | 让侧栏认出 `.pdf` 这个扩展名 |
| `files:view` | 交出会在沙箱里真的跑起来的界面代码（画布渲染 PDF） |

沙箱是浏览器的 iframe 沙箱：这段界面代码**读不到你的文件**，也够不到花笺的任何能力 ——
它只能拿到宿主递给它的那一份 PDF 字节，以及下面说的这条存数据的通道。

## 还没做的

* **马克笔与批注** —— 会做成一个单独的插件（它依赖这个插件）。
* **搜索**：页面上能选中、能复制了，但还没有查找框。
* **扫描件的 OCR**：对方本来就是图片的话，只能看，不能选。
* **日韩文字或非内置字体**：pdf.js 遇到这些会去取额外的字体数据，而沙箱取不到外部资源，
  那些字会缺。等真碰到再说。
* **加密文档**：能认出来并说「打不开」，但不会提示输密码。

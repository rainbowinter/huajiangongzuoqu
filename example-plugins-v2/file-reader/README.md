# 文件读取器

让左侧工作文件夹认识三十多种常见格式 —— 不装它的时候，那儿只看得见 `.md`。

## 用它

装上就生效，没有开关。原来不显示的文件会带着**徽章和颜色**出现在侧栏，点开按格式展示：

| 展示方式 | 认这些 | 能改吗 |
|---|---|---|
| **代码着色** | js / mjs / cjs / jsx · ts / tsx · py / pyw / pyi · rs · go · java · kt / kts · swift · c / h · cpp / cc / cxx / hpp · cs · rb · php · json · yml / yaml · toml · xml · html / htm · css / less · scss / sass · sql · sh / bash / zsh · ps1 / psm1 | **能编辑，保存写回磁盘** |
| **纯文本** | txt / text · log · ini · cfg / conf · env · properties | 能编辑 |
| **Markdown 预览** | markdown / mdx | 能编辑，有预览窗格 |
| **表格** | csv / tsv | **能编辑**（编辑看原文，预览看表格） |
| **图片** | png · jpg / jpeg · gif · webp · bmp · ico · avif · svg | 只读 |
| **音视频** | mp3 · wav · ogg · flac / m4a · mp4 · webm · mov · mkv / avi | 只读 |

每个格式的颜色取的是各语言社区的惯用色（GitHub linguist 那一套）—— 扫一眼卡片就能认出类型，
不必读文字。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `files:register` | 告诉宿主「这个扩展名是什么、该怎么显示」 |

**它不读任何文件，也拿不到任何路径。** 这个插件只提供「格式知识」：文件夹里有哪些文件、
内容是什么，全部由宿主提供。所以它既不需要、也得不到任何文件系统权限。

这也正是把「浏览」和「认格式」拆开的好处：不装它，宿主只剩内置的 Markdown 一条规则；
装上之后侧栏、颜色、徽章、预览方式一次性就位，宿主代码一行没改。

## 还没做的

* **认不出的扩展名不会出现**在侧栏里（比如 `.docx`、`.zip`、`.exe`）—— 不是「点开说暂不支持」，
  而是压根不列出来。
* 表格只有「看」的两种方式：预览是解析好的网格，编辑是**原始文本** ——
  不能点进单元格里改，也不做列宽调整。
* 高亮用的是内置的那套语言，冷门语言会退化成纯文本 —— 不会报错，只是没颜色。

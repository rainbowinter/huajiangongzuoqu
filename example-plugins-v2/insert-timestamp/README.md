# 插入时间戳

一个快捷键插当前时间，外加两个顺手的编辑动作。

## 用它

| 入口 | 动作 |
|---|---|
| **Ctrl+Shift+D** | 在光标处插入当前时间（上下各留一个空行） |
| 命令面板搜「把选中文本包成行内代码」 | 选中的字前后各加一个反引号 |
| 编辑器右键菜单 →「把选中内容写入剪贴板式引用」 | 选中的**每一行**前面加 `> ` |

时间格式在「设置 → 插件 → insert-timestamp」里选：

| 选择 | 插入的样子 |
|---|---|
| 日期时间（默认） | `2026-10-14 09:30:00` |
| 只有日期 | `2026-10-14` |
| ISO | `2026-10-14T09:30:00` |

第三条是给「引用别处一段话」用的 —— 选中三行，得到的是三行 `>` 引用块，
而不是在整段外面套一对引号。

**快捷键抢不过宿主。** Ctrl+B / Ctrl+I 这类内置的 Markdown 快捷键**先**处理，
插件的键位只在宿主没处理时才轮到。所以别指望用插件覆盖内置键位（这是有意的，
不然装一个插件就可能废掉工具栏上的加粗按钮）。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:command` | 注册两条命令（快捷键与命令面板都挂在这上面） |
| `ui:menus` | 往编辑器右键菜单里加条目 |
| `editor:write` | 往正文里插字、改选区 |

## 还没做的

* 格式是**固定的三种**，不能自定义（想加 `2026年10月14日` 这种得改插件源码）。
* 没有「插入当前日期」的独立快捷键 —— 换格式要去设置里改，不能一次按出两种。
* 只有插入：没有「把选中的日期文本改成别的格式」。

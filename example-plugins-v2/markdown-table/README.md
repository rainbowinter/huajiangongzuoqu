# 快速表格

选中几行用空格或制表符分开的文字，按 **Ctrl+\\**，变成一张 Markdown 表格。

## 用它

从别处粘一段数据进来（Excel、日志、`ls -l` 的输出都行），选中，按 Ctrl+\\：

```text
姓名 年龄 城市
张三 28   北京
李四 35   上海
```

变成：

```markdown
| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 张三 | 28 | 北京 |
| 李四 | 35 | 上海 |
```

* **第一行当表头**（就是那一行 `---` 分隔线插在它下面）；
* **列数取最多的那一行**，短的行右边补空单元格 —— 参差不齐的输入不会把表格弄歪；
* 空行直接忽略。

分隔方式在「设置 → 插件 → markdown-table」里选：

| 选择 | 行为 |
|---|---|
| **制表符优先（默认）** | 行里有 Tab 就按 Tab 切（**保留单元格内的空格**）；没有 Tab 才按连续空白切 |
| 只按空白切分 | 一律按空白切，单元格里放不了空格 |

从 Excel 直接粘过来的正是第一种：列是 Tab 隔的，而单元格里往往带空格。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `editor:read` | 拿到选中的那段文本 |

只有读，**没有写** —— 插件返回一段新文本，替换选区的动作由宿主完成，所以能用原生
撤销栈撤销（Ctrl+Z 退回原样）。

## 还没做的

* **单元格里的 `|` 不转义**：内容本身带竖线的话，表格会被切乱 —— 得手工改成 `\|`。
* **只有一列的选区不转**（返回「我处理不了」）—— 那种情况宿主的表格模板会接手，
  给你一个空表格。
* 没有对齐（`:---:`）选项：生成的永远是左对齐的 `---`；想要别的自己在结果上改。
* 不做反向操作：已经是表格的文本不会变回制表符分隔。

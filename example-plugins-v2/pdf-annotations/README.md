# PDF 批注

在 PDF 上圈画、划重点、钉批注。**依赖「PDF 阅读器」**——那个没装/没开的时候，这个也不会跑。

## 用它

打开一个 PDF，预览区顶上那排控件里会多出两样：

| 控件 | 干什么 |
|---|---|
| 标注方式 | 切换当前的工具（按钮上写的就是现在这个） |
| 颜色 | 四种颜色，选中的那个画成色块 |

工具：

- **指针**（默认）：不画东西。鼠标移到已有的标注上会冒出一个小 ×，点它就删掉。
- **矩形** / **圆形**：在页面上按住鼠标拖一个框。
- **自由笔**：按住随便画，松开就是一条线。
- **文字选区**：像在网页上那样**划过去选中文字**，一松手就高亮。行盒是按文字的真实位置算的，
  所以高亮贴着字走，不会圈住一整块空白。
- **图钉批注**：在页面上点一下，弹出一个小框写字，回车保存。鼠标移上去就能看到内容。

标注跟着**缩放和旋转**走：换个比例、把页面转 90°，它们还在原来的位置 —— 存的是 PDF 自己的
坐标，不是屏幕坐标。

## 导出成 PDF

顶上那排控件最右边的「导出」会把标注**写进 PDF 本身**，另存成 `原来那个名字-批注.pdf`
（**原文件不动**）。写进去的是标准 PDF 批注，Edge / Acrobat / WPS 打开就能看到、能改。

注意这**不是同步**：导出之后你再改批注，得重新导一次。

## 标注存在哪

存在**那个 PDF 旁边**的 `__floral-notepaper__/pdf-annotations/` 里，一个 PDF 一份 JSON。
把 PDF 拷到别处、发给别人，标注跟着走；删掉那个文件夹里的东西就等于清空批注。

> 花笺自己的文件树里**看不到** `__floral-notepaper__`（扫描时会跳过它）。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `files:view` | 把界面代码并进 PDF 阅读器的沙箱视图里（标注那一层是这么进去的） |
| `workspace:cache` | 在 PDF 旁边建 `__floral-notepaper__/` 写标注数据 |

导出时不额外要权限：**存到哪儿由你在保存对话框里挑**，插件拿不到路径。

## 还没做的

- **撤销 / 重做**：画错了只能删掉重画。
- **移动已有的标注**：现在只能删。
- **批注列表**：钉了十几个图钉之后，没有一栏把它们列出来。
- **导出成图片 / 打印**：只能另存成 PDF（批注是写进 PDF 的注释对象，不是烧进画面）。
- 导出**不是增量更新**：pdf-lib 会整份重写，签名过的 PDF 导出后会失效。

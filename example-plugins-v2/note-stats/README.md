# 笔记统计

数一数你改了多少次笔记 —— 本次会话，以及**跨会话累计**。

## 用它

打开右侧栏的**「统计」**面板，两行数字：

| 数字 | 含义 |
|---|---|
| 本次会话内容变化 | 从这个窗口打开到现在，正文变了多少次 |
| 累计（跨会话） | 历史上的总次数，重启应用也在 |

正文每变一次（打字、格式化、粘贴…）两个数都加一。

* **想在任意时刻把这个数存下来**：顶上工具栏里有颗 **「保存统计」**，点一下写盘并弹个提示；
* 就算不点，**关窗口时也会自动存一次**（插件卸载时统一写一次，比每敲一个字就写盘安静得多）；
* 「设置 → 插件 → note-stats」里的**「保存时提示」**打开后，每次笔记变化会弹一个
  Toast —— 默认关着，它主要是用来演示事件总线的。

数字落在**数据目录**的 `plugin-data/note-stats/` 下，**与插件代码分开**：升级插件、
甚至整个删掉重装插件，这个数都还在。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `events` | 订阅 `editor:contentChanged` / `note:opened` / `note:changed` |
| `storage` | 把累计数存进插件自己的数据目录 |
| `ui:panel` | 右侧栏里那个面板 |
| `ui:toast` | 「已保存」那条提示 |

多窗口要留意：插件**每个窗口各跑一份**，所以同一刻开两个窗口，两边各数各的；
而存储是**同一只文件**，同时写是「后写覆盖」。这里只在卸载与点按钮时写，
实际撞不上。

## 还没做的

* 数字**只增不减**，不区分窗口：开两个窗口打字会被算两次。
* 没有按天 / 按笔记的细账 —— 就只有两个总数。
* 存的是「变化次数」而不是字数：不记录写了多少字，也不画曲线。

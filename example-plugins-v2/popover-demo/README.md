# 浮层样例

工具栏上一颗「☺」按钮，点开是一个分两类的表情 / 符号面板，点格子插进正文。

## 用它

顶上工具栏里点**「☺」**，弹出一个 240px 宽的小面板：

* 两个页签：**表情**（😀 😅 🤔 👍 🎉 ✅ ❌ 🔥）、**标记**（★ ☆ ❤ ⚠ → ← ↑ ↓）；
* 点任意一个格子 → 插到光标处，面板**不关**，可以连着点好几个；
* 点面板外面、或者按 Esc 收起。

**这个插件主要是给写插件的人看的。** 它演示 `api.ui.registerPopover` 的三个要点，
拿它当模板改比自己从零写快：

1. **`render()` 每次点开调一次**，返回下拉里的 HTML；
2. **`onClick(ref)` 里的 `ref` 是点击落点的描述符**，不是 DOM 节点。点击常常落在格子
   内部的元素上，所以要用 `ref.closestClass("pd-cell")` **往上找那一层**再取 `data-*`；
3. **`onClick` 返回字符串时，宿主会把它当成新内容换上** —— 页签切换就是这么实现的
   （插件在沙箱里自己记住当前是哪一页，不必重新注册）。
   返回 `undefined` 就是不换内容。

面板 HTML 会经宿主消毒，`data-*` 只放行 `index` / `id` / `key` / `value` 四个键 ——
所以「当前是哪个页签」只能靠 **class** 表达（`pd-tab-on`），自造的 `data-active`
会被静默剥掉。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:popover` | 工具栏上的浮层按钮 |
| `ui:style` | 面板自己的样式（页签与格子的悬停反馈） |
| `editor:write` | 把选中的符号插进正文 |

颜色用的是主题变量，深色 / 浅色主题自动跟着变。

## 还没做的

* **不能自己加符号** —— 两份清单写在源码里，想改就得改插件。
* 面板宽度固定 240px，不随内容或窗口变。
* 只插入，不做「点一下删除刚才那个」。
* 严格说它不是个实用插件：想要的是**一份能照抄的浮层模板**。

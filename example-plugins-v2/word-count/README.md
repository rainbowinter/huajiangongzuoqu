# 选中字数

在状态栏显示选中的那段文字有多少字。

## 用它

用鼠标选一段文字，底部状态栏右下角就多出一个小读数：

```text
选中 128 字
```

**没选中东西的时候它什么都不显示** —— 状态栏就那么点地方，空着比挂个 `0` 好。

统计方式在「设置 → 插件 → word-count」里选：

| 选择 | 数什么 | 例子 |
|---|---|---|
| **字符数（默认）** | **忽略空白字符**的字符数 | 换行、空格、Tab 都不算 |
| 词数 | 按空白切出来的段数 | 适合英文 |
| 行数 | 一共几行 | 选中的每一行都算，包括空行 |

「字符数忽略空白」是有意的：数中文段落时，缩进与换行不该让数字虚高。按「词」切分
对中文其实不准（中文词之间没有空格）—— 中文用默认的字符数就好。

## 它要的权限

| 权限 | 为什么 |
|---|---|
| `ui:statusbar` | 在状态栏加一格读数 |
| `editor:read` | 拿到选中的文本 |
| `settings` | 读「统计方式」这条设置 |

只读不写，也不碰文件。整个插件跑在 Worker 沙箱里，宿主把选区文本传给它的渲染函数，
它只回一个字符串。

## 还没做的

* **只有选中时才有读数** —— 不做「整篇多少字」的常驻统计（那是 note-stats 那类插件的活）。
* 词数按空白切分，对中日韩文本没有意义。
* 读数不能点：不做「点一下复制字数」这种小动作。
